# ADR-0004 — Цвет корпуса на экранах с вырезом: чистый чёрный

**Дата:** 2026-08-06 · **Статус:** принято · **Развилка:** спека §15.4, §3.5

## Измерено на целевом железе

MacBook Pro Mac16,7 (M4 Pro), macOS 26.5.2, встроенный дисплей:

| Величина | Значение |
|---|---|
| `frame` | `1728 × 1117` @2x |
| `safeAreaInsets.top` | `32` |
| `auxiliaryTopLeftArea` | `(0, 1085, 771, 32)` |
| `auxiliaryTopRightArea` | `(956, 1085, 772, 32)` |
| **Ширина выреза** | **185** |
| Пилюля по формуле `max(notchWidth, 218)` | **218 × 38** |

## Что из этого следует

Вырез уже пилюли: 185 против 218. Пилюля выступает за его границы на **16.5 pt с каждой
стороны** и на **6 pt ниже** (38 против 32). То есть пилюля не прячется внутри выреза —
она обрамляет его, и стык «физический вырез ↔ нарисованный корпус» приходится ровно на
видимую зону, а не скрыт.

Это делает вопрос цвета не косметическим. Любое отклонение от `#000000` даст видимый шов
по трём сторонам выреза.

## Решение

На экранах с вырезом корпус рисуется `NSColor.black` (`#000000`). На экранах без выреза
остаётся токен `--bg` (`#08090a`): там сливаться не с чем, а абсолютный чёрный читается
как провал. Остальные токены не меняются — разница в одну ступень яркости на границе
не видна.

## Не проверено

Визуальное подтверждение отсутствия шва требует запущенного окна. Проверяется в шаге 3.1
пайплайна — это первый пункт чеклиста приёмки спеки §14.
