# ADR-0017 — Работа Codex видна через его хуки

**Дата:** 2026-09-24 · **Статус:** принято · **Уточняет:** ADR-0013, ADR-0014

## Что измерено

2026-09-24, macOS 26.5.2, codex-cli 0.153.4, Codex из приложения ChatGPT.

FSEvents сообщает об изменении содержимого файла при его закрытии, а не при каждой
записи. Пробный файл в `~/.codex/sessions`, открытый на 12 с с четырьмя записями и
`fsync` после каждой: событий два — создание и закрытие.

| Агент | Как пишет транскрипт | Что видит FSEvents |
|---|---|---|
| Claude Code | открывает, дописывает строку, закрывает | каждую строку |
| Codex | держит rollout открытым всю сессию (`lsof`: дескрипторы 12u, 31u, 82u, 248u) | ничего до конца сессии |

Живой ход Codex: rollout дописан в 14:46:56, событий по нему — ноль.

## Решение

**Хуки Codex.** Codex поддерживает хуки с данными в духе Claude Code: `session_id`,
`turn_id`, `hook_event_name`. Flowbar ставит в `~/.codex/hooks.json` одну команду на
`UserPromptSubmit`, `PreToolUse`, `PostToolUse` и `Stop`: она сохраняет JSON события в
`~/.codex/flowbar/<session_id>.json`. Файл открывается и закрывается — FSEvents это
видит. Разбор: начало хода и инструменты — «работает», `Stop` — конец.

Команда ничего не печатает — вывод `UserPromptSubmit` попал бы в контекст модели —
и пишет файл, только если `session_id` состоит из букв, цифр и дефисов: он становится
именем файла.

**Окно удержания для таких сессий — 10 минут.** Конец хода приходит явно, поэтому окно
здесь — страховка от упавшей сессии, а не детектор тишины. Между вызовами инструментов
модель может думать минутами, и 20 с гасили бы точку посреди работы.

**Установка — кнопкой «Подключить» на экране «Лимиты».** Добавляются только свои хуки,
чужие не трогаются, повторная установка ничего не меняет, прежний `hooks.json` один раз
сохраняется как `hooks.json.before-flowbar`. Это первое место, где Flowbar пишет в чужой
конфиг, — поэтому только по явному нажатию.

**Доверие — за пользователем.** Codex хранит `trusted_hash` одобренных хуков в
`config.toml` и не запускает неодобренные. Flowbar этот хеш не пишет: это был бы обход
защиты Codex. Одобрение — один раз, экраном «Hooks need review» при запуске `codex`
в терминале; десктопное приложение этот вопрос не задаёт.

## Что отвергнуто

| Вариант | Почему нет |
|---|---|
| kqueue на открытые rollout-файлы | чтобы узнать, какие файлы открыты, нужен периодический обход процессов Codex через libproc — опрос и зависимость от того, как Codex держит файлы |
| `.codex-global-state.json` | перезаписывается атомарно в такт интерфейсу, а не хода |
| `thread-writer-locks/*.lock` | создаются раз на тред и не удаляются |

## Чем платим

**Один шаг настройки и одно одобрение.** Без них индикатор Codex видит только создание
и закрытие rollout-файлов.

**Хук на каждый вызов инструмента** запускает `sh` и `plutil` — миллисекунды.
