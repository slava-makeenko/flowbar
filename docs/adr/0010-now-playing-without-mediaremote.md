# ADR-0010 — Источник воспроизведения без MediaRemote

**Дата:** 2026-08-08 · **Статус:** принято · **Пересматривает:** ADR-0002, спека §8.4

## Что измерено

macOS 26.5.2. В момент, когда в Safari играло видео:

| Источник | Ответ |
|---|---|
| CoreAudio, `kAudioDevicePropertyDeviceIsRunningSomewhere` | устройство занято |
| CoreAudio, `kAudioHardwarePropertyProcessObjectList` | **`com.apple.WebKit.GPU` выводит звук** |
| MediaRemote, `MRMediaRemoteGetNowPlayingApplicationIsPlaying` | **false** |
| MediaRemote, `MRMediaRemoteGetNowPlayingInfo` | **0 ключей** |

Символы `MediaRemote` находятся через `dlsym`, вызов проходит, обработчик вызывается —
и возвращает пустоту, пока звук объективно идёт.

## Вывод

`MediaRemote` — тот самый фреймворк, которым пользуется системный виджет «Сейчас
исполняется», — закрыт приватным entitlement `com.apple.mediaremote.*` примерно с
macOS 15.4. Выдать его себе нельзя: он проверяется системой и подписывается только Apple.

Спека §8.4 просила проверить статус на актуальной версии перед тем, как закладываться.
Проверено: **путь A недоступен.** Полное повторение системного виджета — с обложкой,
названием и прогрессом для любого приложения — публичными средствами невозможно.

## Решение

Цепочка источников от богатого ответа к бедному. Первый, кому есть что сказать,
выигрывает:

| Порядок | Источник | Что даёт |
|---|---|---|
| 1 | `ScriptingBridgeAdapter(.music)` | трек, артист, длительность, позиция |
| 2 | `ScriptingBridgeAdapter(.spotify)` | то же |
| 3 | `BrowserNowPlayingAdapter` | название вкладки Safari или Chrome |
| 4 | `AudioProcessNowPlayingAdapter` | имя приложения, выводящего звук |

Управление — медиа-клавишами, работает для всего, включая браузер.

Порт `NowPlayingReading` теперь возвращает не `Track?`, а `NowPlaying` с тремя случаями:
`.track`, `.application(name:)`, `.silence`. Это прямое следствие замера: система
позволяет узнать, **кто** играет, даже когда неизвестно, **что** играет. Прежняя пара
«трек или ничего» такое состояние выразить не могла и заставляла бы врать в одну из сторон.

## Чем платим

**Название вкладки может быть чужим.** Берётся выбранная вкладка активного окна, а звук
может идти из фоновой. Отличить их нечем: в словаре AppleScript ни у Safari, ни у Chrome
нет ни одного свойства про звук — проверено грепом по `sdef`.

**Нужно разрешение «Автоматизация»** для Safari и Chrome. Оно и так требовалось для
Music.app и Spotify, новых требований не появилось.

**Обложки и прогресса для браузера нет.** Полоса прогресса скрывается — контракт
`PlaybackSeeking` это уже предусматривал.

## Что осталось верным из ADR-0002

Путь B + C сохраняется целиком: ScriptingBridge для Music.app и Spotify, медиа-клавиши
как универсальное управление. Это ADR его расширяет, а не отменяет.
