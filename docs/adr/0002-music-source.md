# ADR-0002 — Музыка: ScriptingBridge + медиа-клавиши (путь B + C)

> **Отменён ADR-0011:** модуль музыки удалён из приложения.

**Дата:** 2026-08-06 · **Статус:** принято · **Развилка:** спека §15.1, §8.4

## Решение

Метаданные — через ScriptingBridge к Music.app и Spotify. Управление — через системные
медиа-клавиши как универсальный фолбэк. Приватный `MediaRemote.framework` (путь A) не
используется.

## Почему

Путь A закрыт приватным entitlement и в любом случае несовместим с App Store; он ломается
с обновлениями ОС. Путь C в одиночку не даёт метаданных вообще. B + C покрывает
подавляющее большинство сценариев и не требует приватных API.

## Следствия

- Обложка, название и артист доступны только для Music.app и Spotify.
- Для всего остального (браузер, подкасты) экран показывает транспорт без метаданных —
  контракт `NowPlayingReading` обязывает вернуть `nil`, а не заглушку.
- Полоса прогресса скрывается, когда позиция недоступна, а не показывает ноль.
- Нужно разрешение «Автоматизация» и `NSAppleEventsUsageDescription`.
- Спайк проверки MediaRemote из фазы 0 вычеркнут — проверять нечего.

## Проверено

`sdef` отдаёт словари для обоих приложений на macOS 26.5:
Music.app — установлен, словарь есть; Spotify — установлен, словарь есть.
Диалог «Автоматизация» при первом обращении не проверялся: требует запущенного
приложения и участия пользователя. Проверяется в фазе 9.
