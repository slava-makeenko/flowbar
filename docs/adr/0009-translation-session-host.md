# ADR-0009 — Сессию перевода приносит невидимая вью в слое данных

**Дата:** 2026-08-07 · **Статус:** принято · **Уточняет:** регламент §12, спека §8.3

## Что показал SDK

Проверено по `Translation.swiftinterface` из SDK 26.5:

```swift
public class TranslationSession {          // публичного инициализатора нет
  public func translate(_ string: String) async throws -> Response
}
```

Сессию невозможно создать. Единственный путь — модификатор из кросс-импорт-оверлея
`_Translation_SwiftUI`:

```swift
public func translationTask(_ configuration: TranslationSession.Configuration?,
                            action: @escaping (TranslationSession) async -> Void) -> some View
```

То есть системный API модуля доступен **только из SwiftUI-вью**.

## Противоречие

Регламент §12 требует: `Translation` не встречается выше слоя данных. Но получить сессию
можно лишь из вью, а вьюхи живут в `FlowbarUI`, которому импортировать `FlowbarData`
запрещено правилом зависимостей.

## Решение

Вью, владеющая сессией, живёт **в слое данных** рядом с адаптером:

- `AppleTranslationAdapter` — реализует порт `TextTranslating`, объявляет нужную пару
  языков в свойстве `configuration`;
- `TranslationSessionHost` — вью нулевого размера с `.translationTask(configuration)`,
  отдающая сессию адаптеру.

В оболочку хост попадает **стёртым до `AnyView`**: композиционный корень собирает его и
передаёт как непрозрачный параметр `backgroundHosts`. `FlowbarUI` рисует то, что ему дали,
и про `Translation` по-прежнему не знает — проверка `check-layers.sh` и правило §12
не нарушены.

## Цена

`AnyView` в сигнатуре оболочки стирает тип и мешает SwiftUI переиспользовать вью между
перерисовками. Для одного невидимого элемента нулевого размера это не стоит ничего, но
приём не следует распространять на содержательные вью.

## Отдельно: `@preconcurrency import Translation`

`TranslationSession` — обычный несендабельный класс с неизолированным асинхронным методом.
Строгая проверка Swift 6 считает вызов `translate` из главного актора пересылкой между
доменами изоляции и отказывается собирать. Фреймворк рассчитан ровно на такое
использование внутри `.translationTask`; альтернатива — ждать, пока Apple разметит его
для конкурентности. Импорт помечен `@preconcurrency` с комментарием на месте.

## Что осталось непроверенным

Диалог скачивания языкового пакета и поведение при отказе пользователя. Оба требуют живого
взаимодействия и проверяются вручную по чеклисту приёмки.
