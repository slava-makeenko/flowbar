# ADR-0005 — Многомониторность: панель живёт на экране с вырезом

**Дата:** 2026-08-06 · **Статус:** принято · **Развилка:** спека §15.3, §3.4

## Решение

Панель размещается на первом экране, у которого `safeAreaInsets.top > 0` и определены
`auxiliaryTopLeftArea` / `auxiliaryTopRightArea`. Если такого нет — на `NSScreen.main`,
шириной 218. За активным экраном панель не следует.

Пересчёт по `NSApplication.didChangeScreenParametersNotification`: подключение монитора,
смена разрешения, закрытие крышки.

## Почему

Панель имитирует физическую деталь корпуса. Прыжок за курсором на внешний монитор, где
выреза нет, разрушает метафору и делает поведение непредсказуемым. Следование за активным
экраном можно добавить позже опцией; обратное — убрать привычное поведение — дороже.

## Не проверено

На машине разработки один экран. Поведение при подключении внешнего монитора и при
закрытой крышке проверяется вручную в шаге 3.5 пайплайна.
