# ADR-0003 — App Sandbox включается с первого дня, дистрибуция решается позже

**Дата:** 2026-08-06 · **Статус:** принято · **Развилка:** спека §15.2, §10

## Решение

Выбор «App Store или Developer ID» откладывается до фазы 11. До тех пор код пишется
sandbox-совместимым: App Sandbox включён, доступ к папке скриншотов — через
security-scoped bookmark, автовставка ⌘V и MediaRemote в объём не входят.

## Почему

Цена отката асимметрична. Снять песочницу позже — одна галочка. Натянуть её на готовый
код — переписывание всей работы с файловой системой. Поэтому дешёвое ограничение
принимается сразу, а дорогое решение откладывается до момента, когда для него будут
данные.

## Следствия

- Entitlements фазы 1: `com.apple.security.app-sandbox`,
  `com.apple.security.files.user-selected.read-write`,
  `com.apple.security.automation.apple-events`.
- Пользователь обязан один раз выбрать папку скриншотов руками — риск R4 пайплайна.
- Автовставка ⌘V остаётся возможной опцией отдельной сборкой после фазы 11.
