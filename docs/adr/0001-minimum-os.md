# ADR-0001 — Минимальная версия macOS: 15.0 Sequoia

**Дата:** 2026-08-06 · **Статус:** принято · **Развилка:** спека §15.1

## Решение

Deployment target — `macOS 15.0`. Разработка ведётся на 26.5.2 (SDK 26.5).

## Почему

`Translation.framework` доступен с 15.0. При минимуме 14.0 модуль перевода стал бы
опциональным: понадобился бы второй адаптер, скрытие кнопки из рейла и ветвление по
версии ОС в композиционном корне.

## Следствия

- Из плана уходят `UnavailableTranslationAdapter` и ветвление по версии ОС.
- Порт `TextTranslating` остаётся и обязан уметь вернуть `.unavailable` — но по другой
  причине: пользователь отказался скачивать языковой пакет.
- Пользователи на Sonoma отсекаются.
- Поведение на 15.0 не проверяется на машине разработки — риск R2 пайплайна.

## Проверено

`Translation.framework` присутствует в SDK 26.5.
