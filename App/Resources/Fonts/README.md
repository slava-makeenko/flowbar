# Шрифты

Сюда кладётся `InterVariable.ttf` и текст лицензии `OFL.txt`.

Файл шрифта не хранится в репозитории — его нужно скачать один раз:
https://github.com/rsms/inter/releases (вариативный `InterVariable.ttf`).

Inter распространяется под SIL Open Font License 1.1 — бандлить в приложение можно,
текст лицензии обязан лежать рядом.

Без этого файла `Scripts/make-app.sh` предупредит и соберёт приложение с системным
шрифтом. Интерфейс при этом наберётся **не тем рисунком**: спека §5 требует Inter с
включёнными OpenType-фичами `cv01` и `ss03`, в SF Pro этих фич нет.
